This is a chat app that allows people or users to register and login with validated credentials 
Users can also SMS people with recipient validation, but the South African format which is the +27
It allows users to send, discard and store their message texts into a JSON file
It also allws users to manage stored messages using parrallel arrays and using loops too
It adds parallel arrays to track sent, discarded, and stored messages
The features that this chat app has are loading from JSON, searching by ID or by recipient, deleting by hash, and displaying reports
